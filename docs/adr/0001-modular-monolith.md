# ADR-0001: Next.js + NestJS modular monolith

**Статус:** принят для MVP  
**Дата:** 2026-08-14

## Решение

- Next.js App Router обслуживает витрину, кабинет и admin shell.
- NestJS с Fastify adapter предоставляет версионированный REST API `/api/v1`.
- Каталог, pricing, ordering, procurement, crawler и admin остаются отдельными Nest-модулями одного backend-процесса.
- Worker запускает фоновые задачи отдельно, но использует те же доменные правила и контракты.
- PostgreSQL является целевой БД; Redis — очередь, блокировки и cache. Демонстрационный режим использует заменяемые in-memory repositories.

## Почему

Эта граница даёт быстрый MVP без операционной сложности микросервисов, но сохраняет возможность позже вынести crawler, procurement и notifications в самостоятельные процессы.

## Ограничения

- Публичный HTML Books.am не является authoritative quote.
- Живой crawler и копирование медиа выключены до письменного разрешения.
- Admin-команды проверяются сервером; UI не имеет права произвольно менять финансовые состояния.
- Все суммы хранятся целыми AMD, а pricing snapshots не мутируются.
