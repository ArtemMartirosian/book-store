# LUMI Books — frontend

Публичный книжный магазин и операторская админ-панель LUMI Books. Приложение работает на стандартном Next.js App Router, React, TypeScript и Tailwind CSS 4.

## Возможности

- витрина на армянском, русском и английском языках;
- URL с локалью: `/hy`, `/ru`, `/en`;
- каталог, поиск, фильтры и страницы книг;
- корзина с сохранением в браузере;
- реальная отправка COD-заявки в Nest API с `Idempotency-Key`;
- экран будущего личного кабинета; SMS-вход честно выключен до подключения провайдера;
- подключённая к Nest API админ-панель по адресу `/admin`;
- проксирование `/api/v1/*` в NestJS backend.

## Требования

- Node.js `>=22.13.0`;
- npm.

## Установка и запуск

```bash
npm install
npm run dev
```

После запуска Next.js покажет локальный адрес приложения.

## Переменные окружения

По умолчанию browser-side checkout и admin используют same-origin путь `/api/v1`. Укажите внутренний адрес Nest API, в который Next.js будет проксировать этот путь:

```bash
BACKEND_INTERNAL_URL=http://localhost:4000
```

Если API намеренно доступен на отдельном публичном origin, proxy можно не использовать и задать browser-visible URL при сборке; тогда origin витрины должен быть разрешён в `CORS_ORIGINS` backend:

```bash
NEXT_PUBLIC_API_URL=https://api.example.am/api/v1
```

Каталог, главная страница и карточки книг читают импортированные записи из локального Nest API. Без работающего API главная страница сохраняет небольшой демонстрационный fallback, а каталог показывает явную ошибку подключения. `/admin` требует логин и пароль; они хранятся только в памяти React и исчезают при перезагрузке. Служебный `x-admin-api-key` используется только фоновым worker и в интерфейс администратора не передаётся.

Для абсолютных ссылок в Open Graph можно указать:

```bash
NEXT_PUBLIC_SITE_URL=https://example.am
```

## Структура

```text
app/[locale]/                 локализованные публичные маршруты
app/components/storefront/    компоненты витрины и словари HY/RU/EN
app/admin/                    операторская админ-панель
app/lib/                      типы и демонстрационные данные
public/og.png                 social preview LUMI Books
tests/                        контрактные тесты
```

Корневые публичные маршруты перенаправляют пользователя на русскую локаль. Книжные данные сейчас демонстрационные; интеграция с NestJS API подключается через `/api/v1`.

## SEO и язык документа

Каждая локализованная страница формирует собственные `canonical` и `hreflang` для HY/RU/EN и `x-default`. Например, `/hy/catalog` ссылается на варианты `/ru/catalog` и `/en/catalog`, а не на главные страницы языков.

В App Router общий `app/layout.tsx` находится выше динамического сегмента `[locale]`, поэтому он не получает этот параметр напрямую. `proxy.ts` определяет локаль из URL на сервере и передаёт её корневому layout через внутренний request header. Переключатель языка выполняет полную навигацию документа, чтобы сохранять корректный `<html lang>` после смены языка без клиентской мутации DOM и hydration-расхождений.
